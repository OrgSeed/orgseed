# Literature behind the rules

DRAFT. Each entry says what has been read of it for this seed. Where a work was read, a module's Grounding section quotes it with the page. A **[lead]** is a work whose bibliographic record has been seen but which has not been read for this seed: it names a topic a rule's reason touches, and carries no weight as evidence. The second column gives that topic, not a finding. Where part of a work was read, the entry says which part, and only that part is quoted or paraphrased anywhere in the seed. Before any of these is relied on in published work, it is read in full and every claim attributed to it is checked against its text.

Full author names and DOIs are given where a bibliographic record was seen; otherwise surnames and year, with "record not checked".
