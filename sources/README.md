# sources/

Local copies of every source the organization relies on (AGENTS.md, CORE-13): a PDF, a saved page, or a text file. One file per source, named author_year_short-title. If a source cannot be saved (paywall, physical book), save its metadata in a .txt file and mark the claim `lead` in `records/claims.jsonl`.

A source comes here in one of two ways: the founder saves it, or, where the founder has switched on web fetching in the agent app, a member saves the page it fetched and logs the fetch (`source_fetched`, naming the address and this file). What a member remembers is never a source.
